# 👁️🤖 Dhristhi-AI — Real-Time AI Object Detection System

🚀 An advanced browser-based AI Object Detection project built with modern web technologies and powered by Machine Learning.

Dhristhi-AI uses Computer Vision and the COCO-SSD model to detect and track multiple objects in real time directly through your device camera — all inside the browser with a futuristic responsive dashboard UI.

---

## ✨ Features

- ✅ Real-time Object Detection
- ✅ Multi-object Tracking
- ✅ AI-powered Bounding Boxes
- ✅ Confidence Score Visualization
- ✅ Responsive Futuristic Dashboard
- ✅ Glassmorphism UI Design
- ✅ Adjustable FPS Controls
- ✅ Mobile-Friendly Interface
- ✅ Live Camera Feed Detection
- ✅ Real-time Canvas Rendering

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- ML5.js
- COCO-SSD Model

---

## 📌 About the Project

Dhristhi-AI is a browser-based computer vision application that can identify objects such as:

- 👤 People
- 📱 Phones
- 💻 Laptops
- 🍼 Bottles
- 🚗 Cars
- 🐶 Pets
- and many more...

The system processes live camera input and performs AI-based object detection in real time using machine learning directly inside the browser.
